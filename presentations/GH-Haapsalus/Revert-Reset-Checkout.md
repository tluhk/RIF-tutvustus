# **Võrdlustabel: `git revert` vs `git reset` vs `git checkout`**

| **Omadus**                 | **`git revert`**                                            | **`git reset`**                                                                                                                       | **`git checkout`**                                                                                                         |
| -------------------------- | ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| **Peamine eesmärk**        | Tühistab commit-i, luues uue commit-i.                      | Muudab commit-ajalugu või taastab töökausta oleku.                                                                                    | Vahetab harusid, taastab faile või liigub commit-ajaloos.                                                                  |
| **Ajaloo muutmine**        | Ei muuda ajalugu, loob uue commit-i.                        | Muudab ajalugu lokaalselt, eriti `--hard` ja `--mixed` korral.                                                                        | Ei muuda ajalugu, kui ei tehta muudatusi.                                                                                  |
| **Jagatud töövoogudes**    | Ohutu kasutada jagatud repository-des.                      | Ei ole ohutu jagatud repository-des (vajalik `--force` push).                                                                         | Ohutu, kui ei tee commit-e detached HEAD režiimis.                                                                         |
| **Failimuudatuste mõju**   | Tühistab commit-id, jättes muudatused nähtavaks ajaloos.    | Sõltub režiimist: `--soft`, `--mixed` või `--hard`.                                                                                   | Sõltub käsu kontekstist: failid, harud või commit-id.                                                                      |
| **Millal kasutada?**       | Kui soovid vigase commit-i tühistada ilma ajalugu muutmata. | Kui soovid muuta ajalugu ja kõrvaldada commit-id.                                                                                     | Kui soovid: <ul><li>Harule liikuda.</li><li>Faili taastada.</li><li>Commit-ajaloos navigeerida.</li></ul>                  |
| **Käskude näited**         | `git revert <commit_hash>`                                  | <ul><li>`git reset --soft <commit_hash>`</li><li>`git reset --mixed <commit_hash>`</li><li>`git reset --hard <commit_hash>`</li></ul> | <ul><li>`git checkout <branch_name>`</li><li>`git checkout -b <new_branch>`</li><li>`git checkout <commit_hash>`</li></ul> |
| **Commit-ide eemaldamine** | Ei eemalda commit-e, vaid tühistab need uue commit-iga.     | Eemaldab commit-id, kui kasutatakse `--mixed` või `--hard`.                                                                           | Ei eemalda commit-e; ainult muudab aktiivset tööolekut.                                                                    |
| **Failide taastamine**     | Ei mõjuta üksikuid faile.                                   | Võib taastada commit-ide järgi (eriti `--hard`).                                                                                      | Võib taastada failid konkreetsesse commit-i olekusse.                                                                      |
