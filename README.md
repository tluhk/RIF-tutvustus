# Rakendusinformaatika õppekava tutvustavad materjalid

See repositoorium koondab TLÜ Haapsalu kolledži rakendusinformaatika (RIF)
õppekava tutvustamiseks, GitHubi kasutamise selgitamiseks ning tehisintellekti
ja tarkvaraarenduse teemade avamiseks loodud materjale.

Materjalid on mõeldud kasutamiseks esitlustel, töötubades, konverentsidel,
avatud uste päevadel ja õppetöös.

näiteks `README.pdf`, `slaidid.pdf` või teemanimega PDF-fail.

## Kasutamine

Esitlused on valdavalt kirjutatud Markdownis ja mitmed neist kasutavad
[Marp](https://marp.app/) vormingut. Markdowni faile saab lugeda otse GitHubis.
Esitamiseks või PDF-iks eksportimiseks võib kasutada näiteks Marp CLI-d või VS
Code'i Marp laiendust.
